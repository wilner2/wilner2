### 🏆 Destaques

- 📦 Como referência técnica de um time de 5 devs, liderei a migração de um sistema legado de **rastreamento multi-transportadora** para um **monólito modular** com serviços independentes por transportadora. Quando o banco compartilhado passou a travar workers durante migrations, levei a comunicação para **eventos com SNS/SQS**. Resultado: **redução de 50% nos custos de infraestrutura** · [como foi](https://wilnerbruno.dev/artigos/dificuldades-monolito-modular)
- ☁️ Liderei uma **migração Azure → GCP** para a DASA (medicina diagnóstica)
- 🔎 Desenvolvi plataformas de investigação e análise de gastos públicos para o MPMG sobre **milhões de registros** com Elasticsearch, otimizando consultas para um **ganho de 60%** na velocidade de processamento
- 🚨 Instrumentei **7 microsserviços com Dynatrace**; num incidente real, a causa raiz foi encontrada **10 minutos após o alerta** · [como foi](https://wilnerbruno.dev/artigos/campo-undefined-observabilidade-dynatrace)
